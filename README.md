# Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML, CSS, and JavaScript**.

## 🚀 About the Project

This portfolio website showcases my:

* About Me
* Education
* Technical Skills
* Projects
* Current Learning
* Contact Information

The website is designed with a modern dark theme and is fully responsive for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations, and responsive design
* **JavaScript** – Interactivity and functionality
* **Google Fonts** – Inter font

## ✨ Features

* Responsive design
* Modern dark UI
* Fixed navigation bar
* Mobile navigation menu
* Hero section
* About section
* Education timeline
* Skills and progress bars
* Projects showcase
* Contact form
* Smooth scrolling
* Scroll animations
* GitHub and LinkedIn links
* Mobile-friendly layout

## ▶️ How to Run

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No server or additional installation is required.
